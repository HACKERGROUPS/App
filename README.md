# 🚨 Карта тривог — Android

Android-застосунок (Kotlin + Jetpack Compose) — та сама карта тривог, що й
CLI/веб-версії, тільки як окремий застосунок на телефоні, з push-
сповіщеннями та фоновим стеженням.

## Фічі

- 🗺 **Карта** — сітка областей, кольори за статусом
- 📋 **Таблиця** — список із типом тривоги, часом початку, деталями
- ⚙️ **Налаштування**:
  - API-токен alerts.in.ua (поле приховане, як пароль)
  - інтервал оновлення (5–120 с)
  - звук при тривозі/відбої (генерується системним `ToneGenerator`, без
    аудіофайлів) + кнопка "Перевірити звук"
  - push-сповіщення
  - **фонове стеження** — постійне сповіщення, яке продовжує ловити
    тривогу/відбій навіть коли застосунок закрито

## Вимоги

- Android Studio (Koala чи новіше)
- Android 8.0 (API 26) чи новіше на пристрої
- Токен alerts.in.ua (той самий, що й для CLI/веб-версії)

## Збірка і запуск

### Варіант А — Android Studio (на ПК)

1. Відкрийте папку `ukraine-alerts-android` в Android Studio (File → Open).
2. Дочекайтесь синхронізації Gradle (перший раз качає залежності —
   потрібен інтернет).
3. Підключіть телефон (USB-налагодження) або запустіть емулятор.
4. Run ▶ на `app`.
5. При першому запуску дозвольте сповіщення (Android запитає сам).
6. Перейдіть у Налаштування → вставте токен → Зберегти.

### Варіант Б — GitHub Actions (без ПК, прямо з телефона)

У репозиторії вже є `.github/workflows/android-build.yml`, який збирає
APK на серверах GitHub — вам не потрібно нічого компілювати на самому
пристрої.

1. Створіть на GitHub новий репозиторій і залийте туди весь вміст цієї
   папки (через застосунок GitHub, веб-інтерфейс, чи `git push` з ПК).
2. Відкрийте репозиторій → вкладка **Actions**. Якщо збірка не стартувала
   сама (push у `main`/`master`) — натисніть **Android Build** зліва →
   **Run workflow**.
3. Зачекайте, поки прогон позеленіє (зазвичай кілька хвилин).
4. Відкрийте цей прогон → внизу розділ **Artifacts** → завантажте
   `alerts-map-debug-apk` (прийде `.zip`, всередині — `app-debug.apk`).
5. На телефоні розпакуйте zip (якщо качали не з телефону — перекиньте
   APK на пристрій) і встановіть `.apk`. Android попросить дозволити
   "встановлення з невідомих джерел" для застосунку, яким відкриваєте
   файл (Файли / Chrome тощо) — підтвердіть.
6. При першому запуску дозвольте сповіщення → Налаштування → вставте
   токен → Зберегти.

Це **debug-збірка** (підписана тестовим debug-ключем) — цілком придатна
для особистого використання, просто не годиться для публікації в Google
Play.

## Фонове стеження і батарея

Android агресивно вбиває фонові служби на деяких виробниках (Xiaomi,
Samsung, Huawei, OnePlus). Якщо "Фонове стеження" самовільно зупиняється:

- додайте застосунок у винятки оптимізації батареї
  (Налаштування → Батарея → без обмежень для цього застосунку)
- на MIUI/HyperOS додатково увімкніть "Автозапуск" для застосунку

```
│   └── AlertsMonitorService.kt — foreground-служба фонового стеження

    ├── screens/                — MapScreen, TableScreen, SettingsScreen
    └── theme/                  — кольори й тема (узгоджені з CLI/вебом)
```

## Безпека токена

Токен зберігається в DataStore — приватному сховищі застосунку (інші
застосунки без root-доступу його не бачать), **без додаткового шифрування**.
Для суто особистого використання цього достатньо. Якщо захочете посилити —
наступний крок — перейти на `EncryptedSharedPreferences` з
`androidx.security:security-crypto`.

## Примітка від розробки

Код написаний і перевірений на рівні структури та логіки (моделі,
обчислення статусів, diff для сповіщень), але **не компілювався** в
реальному Android SDK/Gradle — середовище, в якому писався код, не мало
мережі для завантаження Android-залежностей. Якщо при першій збірці
Android Studio покаже помилку — скиньте текст помилки, і я одразу виправлю.
